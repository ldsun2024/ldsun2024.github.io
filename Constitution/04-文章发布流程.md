# 文章发布流程

本文档解释本站从「新建 .md 文件」到「用户浏览器看到页面」的完整流程，包含三个阶段：**发现** → **渲染** → **输出**。

---

## 一、发现流程（Discovery）

Hugo 是一个静态站点生成器，启动时自动扫描 `content/` 目录下的所有文件。

### 1.1 扫描入口

Hugo 读取 `hugo.toml` 配置后，递归遍历 `content/` 目录。本站的文章全部放在：

```
content/posts/
├── 写作创作/
│   ├── _index.md        ← 分类列表页
│   ├── 01-创作工作范式.md
│   └── ...
├── 心静的力量/
├── 认知觉醒/
├── 直播感悟/
├── 随笔杂文/
└── 黑马鉴赏/
```

### 1.2 文件解析

Hugo 对每个 `.md` 文件做两件事：

1. **读取 Front Matter** — 解析文件开头的 `---` 之间的 YAML 元数据：

   ```yaml
   ---
   title: "我的新文章"          # 文章标题
   date: 2025-07-01            # 发布日期
   tags: ["随笔"]              # 标签（至少一个，见排版规则）
   draft: false                # 是否为草稿
   ---
   ```

2. **读取正文** — Front Matter 之后的内容作为 Markdown 正文。

### 1.3 关键过滤：draft 字段

- `draft: true` → 该页面被标记为草稿，**不会出现在生产构建中**
- `draft: false`（或省略该字段） → 正常发布
- 本地预览时加 `-D` 参数（`hugo server -D`）可显示草稿

### 1.4 自动构建内容树

Hugo 根据目录结构自动建立页面层级（Page Tree），无需手动注册：

```
content/posts/                            → Section: "posts"
  ├── 随笔杂文/_index.md                   → 子节列表页
  │   ├── 12-欢迎.md                      → RegularPage
  │   └── 13-我的新文章.md（你新增的）      → 自动识别为 RegularPage
  ├── 写作创作/_index.md
  └── ...
```

**结论：** 只要 `.md` 文件放在 `content/posts/<分类>/` 下，Hugo 自动发现它，无需任何配置文件登记。

## 二、渲染流程（Rendering）

Hugo 将「内容（.md）」与「模板（layouts/）」结合，生成 HTML 页面。

### 2.1 模板层级

```
layouts/
├── _default/
│   ├── baseof.html      ← 所有页面的基础骨架（HTML 头、导航栏、页脚）
│   ├── list.html        ← 列表页模板（归档页、分类页）
│   └── single.html      ← 单篇文章模板
├── index.html           ← 首页模板
└── 404.html             ← 404 页面
```

### 2.2 渲染匹配规则

Hugo 根据页面类型自动选择模板：

| 页面类型 | 对应路径 | 使用的模板 |
|---------|---------|-----------|
| 首页 | `/` | `layouts/index.html` |
| 文章列表 | `/posts/` | `layouts/_default/list.html` |
| 分类列表 | `/posts/随笔杂文/` | `layouts/_default/list.html` |
| 单篇文章 | `/posts/随笔杂文/13-我的新文章/` | `layouts/_default/single.html` |

### 2.3 首页渲染（index.html）

首页从 `content/_index.md` 读取内容，展示英雄区（标题 + 描述）和最新文章列表。

### 2.4 列表页渲染（list.html）

归档页 `/posts/` 的核心逻辑（第 14-15 行）：

```go-html-template
{{ $pages := .Pages }}
{{ if not $isTag }}{{ $pages = where .Site.RegularPages "Section" "posts" }}{{ end }}
```

- `.Site.RegularPages` — 全站所有**常规页面**（非草稿、非 _index.md）
- `where ... "Section" "posts"` — 筛选出属于 `posts` 目录下的文章
- `.Paginate $pages 20` — 每页 20 篇，支持分页
- `.GroupByDate "2006"` — 按年份分组显示

**任何新增的、draft: false 的文章都会被这个 `where` 筛选器自动包含。**

### 2.5 单篇文章渲染（single.html）

```go-html-template
<h1>{{ .Title }}</h1>                    ← 读取 Front Matter 的 title
<span>{{ .Date.Format "2006-01-02" }}</span>  ← 读取 Front Matter 的 date
{{ .Content }}                            ← 将 .md 正文转为 HTML
{{ with .Params.tags }}                   ← 读取 Front Matter 的 tags
```

- `.PrevInSection` / `.NextInSection` — 自动生成同分类内的上一篇/下一篇导航
- `.ReadingTime` — 自动计算阅读时长

### 2.6 渲染流程总结

```
.md 文件
  │
  ▼ 解析 Front Matter → 提取 title, date, tags, draft 等
  │
  ▼ 解析 Markdown → 转为 HTML（{{ .Content }}）
  │
  ▼ 套用 baseof.html → 加上导航栏、页脚等页面骨架
  │
  ▼ 根据页面类型匹配 list.html 或 single.html
  │
  ▼ 输出完整 HTML
```

## 三、输出流程（Output）

Hugo 将所有渲染好的页面写入磁盘，然后部署到线上。

### 3.1 本地构建输出

执行 `hugo`（不带 `-D`）后，所有页面输出到 `public/` 目录：

```
public/
├── index.html                     ← 首页
├── posts/
│   ├── index.html                 ← 归档页（第 1 页）
│   ├── page/2/index.html          ← 归档页（第 2 页，如有）
│   ├── 随笔杂文/
│   │   ├── index.html             ← 随笔杂文分类列表页
│   │   ├── 12-欢迎/index.html     ← 单篇文章
│   │   └── 13-我的新文章/index.html ← 你新增的文章
│   ├── 写作创作/
│   └── ...
├── tags/
│   └── ...                        ← 按标签生成的页面
├── css/
├── js/
└── ...
```

`public/` 目录就是完整的静态网站，可以直接用浏览器打开。

### 3.2 上线部署流程（GitHub Actions）

配置文件：`.github/workflows/hugo.yaml`

```
你推送代码到 main 分支
        │
        ▼
GitHub Actions 自动触发
        │
        ▼
Step 1: Checkout — 拉取最新代码
        │
        ▼
Step 2: Setup Hugo — 安装 Hugo 0.128.0
        │
        ▼
Step 3: Build — 运行 hugo --verbose
        │       （注意：不加 -D，草稿被排除）
        │
        ▼
Step 4: Upload artifact — 将 public/ 上传为部署制品
        │
        ▼
Step 5: Deploy to Pages — 推送到 GitHub Pages 环境
        │
        ▼
用户访问 https://ldsun2024.github.io 看到最新内容
```

### 3.3 关于 draft 的影响

| 命令 / 场景 | draft: true | draft: false |
|------------|------------|-------------|
| `hugo server`（本地预览） | ❌ 不显示 | ✅ 显示 |
| `hugo server -D`（预览含草稿） | ✅ 显示 | ✅ 显示 |
| `hugo --verbose`（生产构建） | ❌ 不显示 | ✅ 显示 |
| GitHub Actions 部署 | ❌ 不上线 | ✅ 上线 |

---

## 四、新增一篇文章的完整流程

```
1. 在 content/posts/<分类>/ 下新建 .md 文件
        │
2. 填写 Front Matter（title, date, tags, draft: false）
        │
3. 撰写 Markdown 正文
        │
4. 本地预览：hugo server -D
        │
5. 确认无误后，推送代码到 main 分支
        │
6. GitHub Actions 自动构建并部署
        │
7. 线上生效 ✅
```

**核心要点：** 文件放在 `content/posts/` → `draft: false` → 自动被发现 → 自动渲染 → 自动上线。
