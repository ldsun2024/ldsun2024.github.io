# 情绪周期与黑马股起涨特征

> 黄金课 ｜ PDF p452-463 ｜ 授课时间：2023 年 4 月 23 日

## 概述

本篇从"情绪"入手，讲 K 线形态随情绪演变的几个阶段（纠结期、犹豫期、加速期、见顶期），并归纳黑马股见底起涨的四个特征，最后以西部矿业等作案例分析。

## 核心概念

- **情绪**：股市里还有一个最重要的一点，就是情绪。
- **K 线形态的四个阶段**：纠结期 → 犹豫期 → 加速期 → 见顶期。周线买法则对应：犹豫期 → 加速期 → 沸腾期 → 赶顶期。

## 见底的确认与介入时机

- 见底之后直接跳空涨停：若是**日线级别**，第二天就要进；若是**周线**，还需要等。
- 周线买法一定要有犹豫期、加速期、沸腾期、赶顶期；**周线见底不要着急买，一个周线的底需要反复确认**。
- 见底之后，如果**没有涨停、没有 7% 以上的涨幅，不要介入**；小阴小阳磨磨唧唧的也不要碰。
- 加速洗盘期：大阴线、大阳线反复洗盘。

## 大涨之前的特征

1. **脱离底部的 3 买**。
2. 经过**大幅下跌的洗盘**。
3. 会有一个**中枢背驰**（也可能是日线背驰），背驰之后出现有效的 3 买，见底后震荡就很规律。
4. **一定有涨停、跳空**。

## 案例分析

- **西部矿业**：见底、中枢符合要求，日线级别中枢背驰，周线 3 买，站上 60 天线；最新的中枢下轨正好卡在前一个中枢的上轨，然后反复震荡。**周线的破位 3 买，涨幅 1 倍以上。**
- **比亚迪**：周线的 3 买震荡肯定不是出货，最后一笔为周线级别 3 买破位一笔，月线 4 买。
- **神农科技**：贴 60 天线要走好，贴 20 天线也要走好。
- 昆仑万维（鹰抓功）：先回踩 60 天线拉一波，然后回踩 20 天线拉一波；**想大涨，指标一定要打下来**。
- 其他案例：瑞和材料（反转期）、东方雨虹、赣锋锂业、中芯国际（攻击中枢）、盛大资源。

## 小结

- 情绪是股市最重要的一点，K 线形态随情绪经历纠结期→犹豫期→加速期→见顶期。
- 周线见底要反复确认，不要着急介入；没有涨停、没有 7% 以上涨幅就不介入。
- 大涨前有四个特征：脱离底部的 3 买、大幅下跌的洗盘、中枢背驰后的有效 3 买、涨停与跳空。
- 选股看中枢位置：中枢下轨卡在前中枢上轨者为佳；贴 20、60 天线都要走好。
