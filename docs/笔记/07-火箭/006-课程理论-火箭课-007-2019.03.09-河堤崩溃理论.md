# 河堤崩溃理论

> 火箭课 ｜ PDF p116-119 ｜ 授课时间：2019 年 3 月 9 日

## 概述

本篇讲"河堤崩溃理论"在选股上的应用：以日线 3 买为核心买点，强调下跌不能放量，并给出大盘回调时预判板块轮动的方法。

## 3 买的位置与量能

- 泽熙就是做日线 3 买。
- **3 买的下跌一定不能放量。**
- 连续三个涨停。

## 大盘回调时的选股

- 大盘回调的时候，要去找日线级别 3 买的票；一定是在大盘这笔回调形成背驰的时候。等大盘反弹的时候去找，就完了。
- 要在大盘还没有见底的时候，去预判板块轮动。
- 板块的 3 买一定要在板块已经开始反弹的时候；日线 90% 的票不会这么拉。

## 小结

- 3 买的下跌一定不能放量。
- 大盘回调到背驰时，去找日线级别 3 买的票。
- 板块 3 买要在板块已经反弹起来时介入。
