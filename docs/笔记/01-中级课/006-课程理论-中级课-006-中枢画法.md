# 中枢画法

> 中级课 ｜ PDF p24

## 概述

本篇为课堂要点摘录，围绕中枢的画法与意义：线段分上涨、下跌两种，中枢画错就会乱操作；中枢像黑洞一样有引力。

## 线段与中枢

- 线段分 2 种：上涨或者下跌。
- 不创新低，反创新高；不创新高，反创新低。
- 有效，无效，这样才对劲。

## 中枢的引力

中枢是有引力的：你往上走，我把你拉回来；你往下走，我把你拉回来——黑洞。

## 执行力

- 中枢不对，你就会乱操作，乱操作就会亏损。
- 一次错了，可以让你赔很多钱。
- 执行力。
- 树叶、菜花——大自然神奇之处（课堂类比）。
