## 站点特性

- 顶部导航：首页 / 经典语录 / 笔记（含各课程入口）/ 案例分析 / 其它
- 导航与侧边栏由 `docs/.vitepress/config.mts` 自动扫描 `docs/笔记/` 目录生成——新增分类或文章不需要手动改配置
- 全文搜索（`Ctrl + K`）、深色模式、上一篇 / 下一篇、最后更新日期
- 首页为书法海报页：「只有无与伦比的专注，才有超乎想象的回报」

## 本地开发

需要 Node.js 20+：

```bash
npm install       # 安装依赖
npm run dev       # 本地开发预览（热更新）
npm run build     # 生产构建，输出到根目录 dist/
npm run preview   # 预览构建产物
```

## 目录结构

```
.
├── docs/                        # 站点源文件
│   ├── .vitepress/config.mts    # 站点配置（导航 / 侧边栏自动生成）
│   ├── index.md                 # 首页（书法海报）
│   └── 笔记/                     # 课程笔记（10 个分类）
├── .github/workflows/deploy.yml # 自动部署工作流
└── package.json
```

## 部署

推送到 `main` 分支即自动构建并发布，无需手动操作：

```bash
git add .
git commit -m "更新笔记"
git push
```

工作流（`deploy.yml`）流程：`npm ci` → `npm run build` → 上传 `dist/` → 发布到 GitHub Pages。

构建进度与结果见仓库的 Actions 页面，也可以在 Actions 页面手动触发（Run workflow）。
